# Autoladder 디자인

**이 문서는 기록이다. 앱 화면은 만들지 않기로 했다 (2026-11-24).** Claude Code + 공정 흐름도 + 검증 결과서로 대신한다. 아래는 화면을 만들려던 때의 선택과 시안이다.

당시 상태: 선택 3가지 확정, 5개 화면 시안은 사용자 승인 전.

시안은 비공개 캔버스에 있다 (윗줄 = 구성 비교 A·B·C, 아랫줄 = 확정안의 ①②③⑤ 화면, ④는 윗줄의 A).

방향 변경(2026-11-24): 앱 안에서 Claude를 부르지 않는다. ② 공정 입력 화면의 "단계 표 초안 만들기"는 없애고, 화면은 프로젝트 파일을 열어 보고 고치는 용도로 줄인다. 시안의 ②는 이 변경 전 모습이다.

## 확정한 것

| 항목 | 결정 |
|---|---|
| 화면 구성 | 단계형. 위에 ①~⑤ 단계 표시줄, 한 번에 한 화면, 아래에 이전·다음 버튼 |
| 래더 그림 | GX Works2와 비슷하게. 디바이스는 접점 위, 코멘트는 아래, 스테이트먼트는 렁 위 |
| 테마 | 밝은 테마 하나, 파란 강조색 |

## 화면

1. 할당표: 파일 열기 / 붙여넣기 / 행 추가, 표(행, 주소, 이름, 의미, 방향, 접점), 행 수와 오류 수
2. 공정 입력: 공정 설명 글상자 + "단계 표 초안 만들기", 또는 "빈 단계 표로 가기"
3. 운전 설정: 항목마다 주소 선택. 이름에서 추정한 값은 "확인"을 눌러야 적용. 지정하지 않아 만들지 않는 기능을 아래에 모아 보여 줌
4. 단계 표: 표(순서, 단계, 켜지는 출력, 넘어가는 조건, 다음 단계), 단계·단계 이동·횟수 세기 추가, "래더 만들기"
5. 결과: 렁 수·오류·경고, 래더 그림(읽기 전용), "GX Works2용 CSV 내보내기"

## 디자인 값

색

| 쓰임 | 값 |
|---|---|
| 바탕 | `#F4F6F9` |
| 표·패널 면 | `#FFFFFF` |
| 글자 | `#1B2430` |
| 보조 글자 | `#4A5565` |
| 아직 안 간 단계 글자 | `#5B6675` |
| 테두리 | `#D9DEE6` (표 행 사이 `#EEF1F5`, 버튼 `#B8C0CC`) |
| 강조(주 버튼) | `#1D5FD1`, 글자 `#FFFFFF` |
| 현재 단계 | 면 `#E6EEFB`, 글자 `#174BA6` |
| 경고 상자 | 면 `#FFF6E5`, 테두리 `#E0B565`, 글자 `#5C3A00` |
| 스테이트먼트 | `#2F6B3A` |
| 래더 선 | `#1B2430`, 접점·코일 2px, 모선 3px |

글꼴

- 본문: Noto Sans KR 14px (제목 22px 굵게, 표 머리글 13px). 앱에서는 글꼴 파일을 넣지 않고 시스템 한글 글꼴로 대체할 수 있다
- 주소·디바이스: 고정폭(JetBrains Mono) 12~13px

간격과 크기

- 화면 여백 24px, 묶음 사이 16px, 버튼 사이 8px
- 버튼·선택 상자 높이 44px, 모서리 6px. 표·패널 모서리 8px
- 표 행 높이 44~48px
- 내용 최대 폭 1180px, 좁아지면 표는 가로 스크롤
